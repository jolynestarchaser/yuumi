# Desktop Polish & Shortcuts

## Goal

เพิ่ม interaction ให้รู้สึกเหมือน desktop จริง

## Keyboard

แนะนำ:
- `Delete` → delete selected item
- `Enter` → open selected
- `Space` → Quick Preview
- `Escape` → close preview / clear selection
- `F2` หรือ custom → rename

## Quick Preview

Space:
- image → large image
- video → player
- link → rich card
- note → note content
- folder → summary/list หรือไม่ preview ก็ได้

## Context Menu

Desktop:
- New Folder
- New Note
- Add Link
- Upload Image
- Upload Video

Item:
- Open
- Rename
- Move
- Delete

## Selection

MVP:
- single select ก่อน

Optional:
- Cmd/Ctrl + click multi-select
- drag selection rectangle

## Wallpaper

ทำเป็น config:
- default cute desk wallpaper
- user เปลี่ยนได้ในอนาคต

MVP อาจใช้ bundled image/CSS background

## Acceptance Criteria

- shortcuts ไม่ทำงานตอนกำลังพิมพ์ input/textarea
- Space เปิด preview
- Escape ปิด preview
- context menu ใช้งานได้

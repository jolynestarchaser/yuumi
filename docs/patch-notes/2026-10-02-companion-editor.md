# Companion dressing room — 2026-10-02

- All 11 species use consistent outlined companion art, including older saves.
- Creation and character settings show every supported species. Custom uses an
  authored cloud base; descriptions do not generate new illustrations.
- Pixel-art selection is retired. Breathing, blinking, care reactions, growth
  effects, animation-off, and reduced-motion support remain.
- The character editor reserves a square stage for its animated SVG preview,
  replacing legacy zoom sizing that let the illustration overlap the next field.
  Preview badges no longer cover name controls.
- Responsive species cards have clear selection markers and keyboard focus.
  Desktop choices scroll separately from the save actions; narrow screens use
  a two-column species grid and a sticky save area.
- Unsaved/saved feedback distinguishes a draft from the shared companion.
  Saving remains revision-checked; edits never grant XP or change memories.
- English and Thai What's New highlights use a fresh release ID, so each profile
  sees the update through the existing acknowledgment flow.

This supersedes the switchable soft/pixel presentation in `19-shared-companion.md`.
No backend rollout flag, gameplay reward, database migration, or deployment changes.
